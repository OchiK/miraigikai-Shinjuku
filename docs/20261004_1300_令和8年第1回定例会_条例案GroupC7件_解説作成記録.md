## 3. 実装計画との差異

実装計画（Antigravity 作成）の議案番号・件名・全文PDFのID・概要PDFのID・全7件の可決／承認は一次資料と一致した。一方、次の点は計画と食い違うか、計画に書かれていなかったため、一次資料と AGENTS.md を採用した。

1. **採決日。** 計画は「2月17日または3月24日」を確かめるよう求めた。確かめた結果は上のとおり、7件とも3月24日。2月17日の会議録（schedule 2）に出てくるのは議案送付の報告だけ。

3. **第41号議案の提出日と採決方法。** ほかの6件の提出日は令和8年2月17日だが、第41号議案の全文PDFの提出日は**令和8年3月24日**で、議案送付の通知は3月19日付け（3月24日の会議録 minute 6）。採決は**起立多数**で、福祉健康委員会の少数意見の報告（20番 佐藤佳一議員）と、討論（37番 さわいめぐみ議員、28番 古畑まさのり議員）があった。本文・台帳・テストは、第41号議案だけこの扱いにした。

## 4. 議案ごとの注意点（本文で断定を避けたもの）

- **第32号。** 条例の目的や基金の使途は全文PDFにない。提案理由と概要資料の「安定的な公共料金の支払を担保するため」だけを使い、基金そのものの説明は足していない。
- **第33号。** 改め文は第23条の語句を改めるだけで、「午前5時」は書かれていない。「午前0時から午前5時まで」→「午後10時から翌日の午前5時まで」は概要資料の記載で、台帳も概要資料を引く（テストで固定）。第3項に加える100分の150の括弧書きと、第1号から削る括弧書きは、条文のとおりに書き、金額がどう変わるかは断定していない。管理職員特別勤務手当という名称も、提案理由と概要資料による。
- **第34号。** 適用日（令和8年2月1日）が施行日（4月1日）より前である。2月1日から3月31日の間は10年以上15年未満の学校医・学校歯科医の14,175円を12,951円とする読替えを、normal・hard にも書いた。同じ14,175円が「10年以上15年未満」と「15年以上20年未満」の改定後の額として並ぶのも、資料のとおり。別表の各金額がどの区分にあたるかは、概要資料の表による。
- **第35号。** 施行日は公布の日で、日付を断定していない（テストで固定）。改め文には役目の名前がなく、第3・4・7・8号に2つ目の金額がある。概要資料の表には各号の最初の金額だけが載っているため、2つ目の金額は改め文の数値として書き、何の額かは「わからないこと」に挙げた。
- **第36号。** 全文PDFの変更は附則第5項の年度と基準日を改めるだけで、経費の5項目と100パーセントの負担割合は概要資料にだけある（テストで、台帳の出典が概要PDFであることを固定）。附則第5項の現在の文は議案にないため、概要資料の説明との関係は断定せず、「わからないこと」に挙げた。
- **承認第1号。** 専決処分の内容は告示（新宿区告示第54号）と補正予算概要による。補正予算額は審議結果PDFが「２億687万円」、概要資料が「206,870千円」と書く。内訳7項目の合計が206,870千円になることを確かめた。附則（施行期日・経過措置）は議案に付いていないため、施行日の節は専決処分の日と選挙の日程を書いた。
- **第41号。** 概要資料の「現行」の表をそのまま使い、全文PDFの条文との数値の一致を確かめた。第19条の2第1号の軽減の割合は、改め文にも概要資料にもないため書いていない（概要資料が示すのは第2号と第3号にあたる5割・2割減額の基準だけ。テストで「7割」を書かないことを固定）。前納の対象は、全文PDFのとおり「世帯主が1月1日に日本国内に住所を有していなかった世帯」で、「外国人」という語は、少数意見と討論の発言者が述べた内容としてだけ書き、すべて発言者に帰属させた（テストで固定）。発言の要旨は会議録の記載で、区の見解ではない。数値（収納率、保険料の増減、運営協議会の反対委員数）は発言者の述べた数字であり、検証していない。

| easy | `この議案は 何ですか` → `何を 変えますか（何を 足しますか）` → `いつから 始まりますか` → `この議案は どうなりましたか` → `わからない こと` |
| normal | `どういう仕組みの話か` → `何が変わるのか（主な変更点）` → `いつから始まるのか` → `この議案のゆくえ` → `分からないこと` |
| hard | `1. 議案の基本情報` → `2. 改め文・条文の内容` → `3. 概要資料が示す改正の位置づけ` → `4. 施行期日と経過措置` → `5. 資料から読み取れない事項` → `6. 一次資料一覧` |

- 見出し構成は `bill-contents-revision.test.ts` が21変種すべてで固定している。
- 「わからないこと」は読者への開示であり、肯定的な事実主張の台帳には含めない。各節の存在と項目数（2件以上）はテストで検証した。
- 承認第1号の結果は「承認」で、easy も【原案可決】のアンカーを使わない（「承認」は初出が本文中に現れるため、アンカーにしていない）。
