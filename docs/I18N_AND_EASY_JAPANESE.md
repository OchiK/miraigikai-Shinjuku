## 表示言語と内容難易度を分ける

`locale = ja` と `difficulty = easy` を組み合わせて「やさしい日本語」を表現する。

「やさしい日本語」を独立localeとして扱わない。

## やさしい日本語の原則

やさしい日本語の目的は、日本語学習の支援ではない。**外国人住民が議案の内容と自分への影響を正しくつかみ、必要なら自分で行動できること**である。読みやすさのために、手続き・条件・法的効果を曖昧にしない。

| | 教育目的（SLA） | このプラットフォーム（行政目的） |
|---|---|---|
| ゴール | 語彙・文法の習得 | 議案の理解と、必要な行動の達成 |
| 専門語 | 簡単な語に置き換える | **公式名称は残し、その場で言い換えを添える** |
| 情報量 | 減らしてよい | **減らさない**。条件・例外も全部残す |
| 誤りの影響 | 学習上の小さな誤解 | 制度の誤解・手続きの取りこぼし |

再設計の経緯と適用範囲は [20260918_1200_やさしい日本語_再設計方針.md](20260918_1200_やさしい日本語_再設計方針.md) を参照。

### 1. アンカー保持プロトコル（必須）

行政用語・法令上の固有名詞・書類名・議決の用語は、平易語に置き換えて消してはならない。初出は必ずこの形で書く。

```text
【正式名称】［ふりがな］（＝やさしい言いかえ）
```

例: `【補正予算】［ほせいよさん］（＝あとから 足す お金）`

- 2回目以降は `【正式名称】` だけでよい。ふりがなと言いかえは初出の1回だけ。
- 言いかえは20字程度まで。定義文にしない。
- ふりがなと言いかえは読み手を助けるメタ情報なので、1文40字の数えかたには入れない。数えかたは `packages/seed/main/easy-japanese-text.ts` の `stripAnchorGloss` が固定する。

### 2. 日付は西暦（＋曜日）

- 元号だけの日付を残さない。`令和8年6月10日` → `2026年（令和8年）6月10日（水）`。2回目以降は `2026年6月10日（水）` でよい。
- 年度も同じ。`令和8年度` → `2026年度（令和8年度）`。
- 法令番号・条例番号（`平成19年 新宿区条例 第61号`、`昭和43年法律第100号`）は日付ではなく**識別子**なので、元号のまま変えない。
- 期限は身体の動作に開く。「消印有効」「必着」を そのまま置かない。

### 3. モダリティ（法的効果）を弱めない

| 原文 | やさしい日本語 |
|---|---|
| しなければならない／ものとする | 〜しなければ いけません |
| してはならない | 〜しては いけません |
| することができる | 〜することが できます |
| することが望ましい | 〜する ほうが いいです |

義務を推奨に、禁止を注意に落とさない。逆に「できる」を義務に強めない。

### 4. 情報量を減らさない

- 1文1情報を基本にする
- 長い修飾を減らす
- 二重否定を避ける
- 主語・対象が曖昧なら補う
- 略語だけで済ませない
- 数字、日付、金額、対象条件は勝手に丸めない。「75歳以上」を「お年寄り」にしない
- 条件と例外を落とさない。「ただし〜の場合を除く」は必ず残す
- 原文で不明なことを補完しない
- 1文は40字以内（アンカーのふりがな・言いかえを除いて数える）
- UIではふりがな支援を検討する

### 5. 4パス処理

一度の書き換えで済ませない。

1. **抽出** — 日付・金額・数量・年齢・期間、固有名詞、モダリティの強さ、行為者を原文から洗い出して控える
2. **書き換え** — アンカー保持プロトコルと上記の規則に従って書き換える
3. **監査** — パス1の一覧と突き合わせ、落ちた数字・弱まった義務・残った元号・40字超の文を直す
4. **組み立て** — 出力フォーマットに並べる

生成プロンプトの全文は [prompts/easy_ja.md](../prompts/easy_ja.md)、AIチャット側は `web/src/lib/prompt/source-code/templates/bill-chat-system-easy.ts`。
用途は違うが、上の1〜4は両方が同じ根拠として参照している。**片方を直したら、もう片方も必ず見ること。**
機械的な検証は `packages/seed/main/easy-japanese-validation.test.ts` が行う。

## 翻訳原則

公式日本語:
`source of truth`

翻訳:
`AI-generated aid`

各翻訳ページに短い表示:

> この翻訳は日本語の公式資料をもとに作成した参考情報です。内容の確認には日本語の公式資料をご利用ください。

## 翻訳更新

翻訳レコードに`source_hash`を持たせる。

日本語元コンテンツのhashが変わった場合:

```text
translation.status = stale
```

再生成後:

```text
translation.status = generated
```

必要なら:

```text
translation.status = reviewed
```

## 中国語

初期は `zh-Hans` を採用。
台湾籍住民への対応として `zh-Hant` を追加しやすいコードにしておく。

## UI翻訳と議案翻訳を分ける

UI翻訳:
- ボタン
- ナビ
- エラー
- disclaimer
- 日付ラベル

議案翻訳:
- title
- summary
- content

UI翻訳はversion control。
議案翻訳はDB。

## 言語fallback

```text
requested locale
 -> translated normal content
 -> Japanese normal content + translation unavailable notice
```

内容がないからといって、別議案の翻訳やモデルの一般知識で穴埋めしない。
