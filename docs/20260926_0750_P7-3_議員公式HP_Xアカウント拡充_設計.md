# P7-3 議員公式HP・X（旧Twitter）アカウント情報の拡充 設計

作成日時: 2026-09-26 07:50
ステータス: 実装済み（Xアカウントのみ。下記の決定を参照）

> **2026-09-26 の決定（実装時）**
> - ウェブサイト（`website_url`）は公式名簿のURL欄だけを入れる方針を維持し、§2.2-3 の名簿外補完はしない。議員詳細の「公式名簿に掲載されているURLです」という表示を正しいまま保つため。
> - Xリストは未ログインでは取得できない（HTTP 402）。本人サイトからのリンク、Web検索、ユーザー提供のリスト抜粋を突き合わせ、プロフィールに「新宿区議会議員」と明記されているか本人サイトからリンクされているアカウントだけを採用した（38名中23名）。残りは手動で補う。
> - RPC は11引数版（`council_members` の upsert を持つ唯一のオーバーロード）だけを同じシグネチャで再定義した。
> - `xUrl` は `CouncilorDetail` ではなく `Councilor` に持たせた（`websiteUrl` と同じ位置）。
対象イシュー: BACKLOG P7-3, ROADMAP Phase 7-D

## 1. 目的と背景

新宿区議会議員（定数38名）の個人活動・政策発信へのアクセス性を高めるため、議員詳細ページ（`/councilors/[id]`）および議員一覧（`/councilors`）において、議員本人の公式ウェブサイト（個人サイト・公式ブログ等）および公式X（旧Twitter）アカウントへのリンクを拡充する。

### 現状の課題
- `council_members` テーブルには `website_url` 列が存在するが、新宿区議会公式名簿（`https://www.city.shinjuku.lg.jp/kusei/gikai01_000112.html`、2026年8月7日時点）にURLが記載されている議員（約22名）のみが登録され、未記載の議員（16名）は `null` となっている。
- 公式X（旧Twitter）アカウントを保持・表示するスキーマ・データ・UI導線が存在しない。
- 有志/公式Xリスト（`https://x.com/i/lists/1656228684964200449?s=20`）が共有されており、これを活用してアカウント同定・突合を行うことが可能。

## 2. 調査・データ収集方針

### 2.1 対象
- 新宿区議会議員 38名（現職・第20期）

### 2.2 データソース
1. **公式名簿（既存）**:
   - `https://www.city.shinjuku.lg.jp/kusei/gikai01_000112.html`
2. **Xリスト**:
   - `https://x.com/i/lists/1656228684964200449?s=20`
   - リスト内アカウントと現職38名の氏名を突合。
   - プロフィール記載（「新宿区議会議員」「新宿区」「会派名」等の自己紹介・活動報告ポスト）および本人サイトからの相互リンク等で本人性を確認。
3. **公式ホームページ / ブログの追加調査**:
   - 名簿未掲載の16名について、政党公認ページ・選挙公報・本人公式ブログ等をWeb検索で同定。
   - 同姓同名・第三者のなりすましアカウントは厳正に除外。確認が取れない場合は `null` とする。

## 3. アーキテクチャ・スキーマ変更

### 3.1 データベース（Supabase / PostgreSQL）
`council_members` テーブルに `x_url` 列を追加する。

```sql
alter table public.council_members
  add column x_url text;

comment on column public.council_members.x_url is '議員本人の公式X（旧Twitter）プロフィールURL';
```

### 3.2 本番インポーター（`import_production_inventory` RPC）
`supabase/migrations/` にて、`import_production_inventory` 関数を更新し、`p_council_members` のレコードセット展開・UPSERT処理に `x_url` を含める。

```sql
insert into public.council_members as current (
  name, name_kana, faction_id, faction_role, roster_key,
  official_url, website_url, x_url, terms, sort_order, is_active
)
select ... item.x_url ...
on conflict (name) do update
set
  ...
  website_url = excluded.website_url,
  x_url = excluded.x_url,
  ...
where (...) is distinct from (...);
```

### 3.3 シードデータ・パッケージ拡張
1. **`packages/seed/main/shinjuku-council-members.ts`**:
   - 型定義 `SeedCouncilMember` に `xUrl: string | null;` を追加。
   - 38名の配列定義に `websiteUrl`（補完分）および `xUrl` を反映。
2. **`packages/seed/production/importer.ts`**:
   - カラムマッピングに `x_url` を追加。
   - `generateInventoryPayload` 内の議員データ変換で `x_url: member.xUrl` をマッピング。
3. **`packages/supabase/types/supabase.types.ts`**:
   - `council_members` の Row, Insert, Update 型に `x_url?: string | null` を追加。
