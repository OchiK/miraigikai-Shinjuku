## 3. 作成の方法

1. PDF を `pdftotext` と `pdftotext -layout` の両方で抽出した（表は layout 版でないと列が崩れる）。
2. 一次資料の記載だけで3段の解説を書いた。資料から確かめられない点は、各解説の「わからない こと」「分からないこと」「出典に記載がない事項」に書き出した。
3. 決算認定4件の款別の表は、手で写さずに PDF から機械抽出した（`kessan.py`）。各列について、款の合計が総計と一致することを確認している。
4. ESCO 事業の3件（第73〜75号議案）は構成が同じなので、案件ごとの値（施設名・工事場所・金額・相手方）を表にして1つのテンプレートから生成した（`esco.py`）。値の写し間違いを3件で揃えて防ぐためである。

### 4-0. 機械検証の限界

- `numcheck.py` は、数値が**その案件の一次資料のどこかに**あれば合格とする。別の項目の金額と取り違えても検出できない。千円単位の値は、資料中の同じ数字列（例: 3）と一致しても合格になる。「約」は各出現位置で判定する。
- `ledger_build.py` の引用照合は、「…」で区切った断片がそれぞれ資料のどこかにあれば合格とし、順序や近さを見ない。短い断片（「令和18年度」など）はほぼ必ず一致する。
- `reviewed_content_sha256` は本文から計算して書き込む。本文を直して `ledger_build.py` を再実行すればハッシュのテストは通る。**本文を直したときは、再実行の前に該当する主張と引用を突合し直すこと。** 引用の照合は PDF テキストを使うため CI では再現できず、vitest 側は台帳の構造（定型注記、出典の範囲、変種ごとの行など）だけを確かめる。
- 主張（`final_claim`）が本文のどの文に対応するかは機械では確かめていない。

いずれも合格しやすい方向の漏れなので、公開レビュー（独立したファクトチェック）で補う。

公開レビューでは、1つの `final_claim` に複数の事実が含まれ、一部だけを支える引用に結び付いていた箇所を修正した。タイトル・要約を含めて事実単位の行に分割し、それぞれを対応する引用へ結び付けた。決算認定について資料が直接述べない「議会が認定するかどうかを決める」等は `needs_source` とした。

数値照合で一次資料に直接ない値は、次の計算値だけである。本文でも計算値であることが分かる書き方にしている。

- 第63号議案（ふつう）の利子補給の合計 1,207千円（520＋440＋23＋224）
- 認定第1号（くわしく）の差 394,186,000円（歳入歳出差引残額5,775,143,580円−純繰越金5,380,957,580円）
- 各段の「約」を付けた概数（丸めが正しいことを確認）

## 5. 書き方で判断したこと

- **議決前であること。** 22件とも議決結果は未掲載。各解説は「審議中」「作成時点（2026-09-30）で議決結果は公表されていない」とだけ書き、結果を予想しない。やさしい版の会期の行は「まででした」ではなく「までです」と書き、テストは R8-3 についてこの行を完全一致で固定した（R8-2 は従来どおり「まででした」）。本文と台帳が議決結果（原案可決・否決など）を述べていないこともテストで確かめる。
- **議決後の扱い。** 議決結果はまず `bills.status` に反映する。ただし審議状況の節（「まだ 決まって いません」「審議中です」「までです」）は古くなるので、結果の掲載後に書き直し、台帳を突合し直してハッシュを更新する必要がある。
- **第69号議案（乳児等通園支援事業の利用料）。** 改め文は「無料とする」を「区長が別に定めるところによるものとする」に改める。改正後に生活保護世帯が無料のままかどうかは資料にない。3段とも「分からない」と明記し、やさしい版には「区役所に確認して ください」を入れた。
- **第70号議案。** 概要資料は根拠を「内閣府令」、議案本文は「平成26年厚生労働省令第61号」とする。関係は資料に説明がないので、両方をそのまま書いた。
- **第72号議案。** 概要資料は「都立学校の…条例の改正に合わせ」、議案本文は「令和8年政令第165号の施行等に伴い」とする。これも両方を書いた。
- **第76号議案の件名。** 提出議案一覧ページは「第2)期」、全文PDFと概要PDFは「第Ⅱ期」。インベントリの `officialTitle` は更新検知のため一覧ページの表記のままとし、解説は PDF の「第Ⅱ期」に従い、くわしい版で両方の表記を併記した。
- **第78〜80号議案の個人情報。** 公開 PDF は相手方の氏名・住所の詳細を「（記載削除）」としている。解説も市区名までにとどめた。
- **ESCO 3件の施設数。** 「防災センター外11施設」は本体と合わせて12施設である。やさしい版だけ合計の数で書き、ふつう・くわしい版は公式の「外11施設」の表記を使った。
- **資料の言葉を超えない。** セルフレビューで、第63号議案のやさしい版の「国の 単価」（資料は「施設等利用給付費の単価改定」とだけ書く）、「中小企業」（資料は「事業者」）、第73〜76号議案の「議決の あとに 本契約を 結ぶ。だから 先に 仮契約を する」という因果の説明、第64号議案の「条例が 変わりました」（改正の成立・施行は資料から不明）を、資料の言葉に戻した。
- **用語の言いかえ（アンカー）。** 言いかえに一次資料にない情報を持ち込まないようにした。たとえば「広域連合」は団体の説明が資料にないため言いかえを付けず、「多文化共生プラザ」は「交流の施設」ではなく「多文化共生の ための 区の 施設」とした。第69号議案の通称（こども誰でも通園制度）も資料にないため使っていない。
