# Project Brief

## 仮称

みらい議会＠新宿区

## 運営形態

個人・趣味・非公式。

## 問題設定

地方議会の公式資料は正確だが、一般住民にとって探しにくく、行政・法令用語が多い。新宿区では外国人住民も多く、日本語の公式資料だけでは情報アクセスに差が生じやすい。

このプロジェクトは、公式情報を置き換えるのではなく、公式情報への入口として機能する。

## 対象利用者

- 新宿区民
- 新宿区で生活・就労・就学する外国人
- 日本語の行政文書を読みづらい人
- 区議会の議案を短時間で把握したい人

## 新宿区で多言語対応を重視する根拠

2026年8月1日現在、新宿区の外国人住民は51,870人。

上位:
- 中国 19,795
- 韓国 9,084
- ネパール 5,727
- ミャンマー 3,763
- ベトナム 2,574

ネパール・ミャンマー・ベトナムだけで12,064人、外国人住民の約23.3%。

したがって初期アーキテクチャは以下の言語を前提にする。

- Japanese `ja`
- English `en`
- Simplified Chinese `zh-Hans`
- Korean `ko`
- Nepali `ne`
- Burmese/Myanmar `my`
- Vietnamese `vi`

Traditional Chinese `zh-Hant` は将来追加候補。台湾籍住民も多いため、利用状況を見て判断する。

## 「やさしい日本語」

他の地域版には現在「ふつう」「難しい」の2段階があるが、外国人住民向けの「やさしい日本語」とは目的が異なる。

新宿区版では:
- easy = やさしい日本語
- normal = ふつう
- hard = くわしく

とする。

## 成功条件

MVPの成功はアクセス数ではなく、以下で判定する。

- 公式資料との対応関係を追跡できる
- 1会期分の議案を欠落なく掲載できる
- AI生成要約に出典がある
- やさしい日本語が通常版より実際に読みやすい
- 7言語へ同じ構造で拡張できる
- AI料金が設定上限を超えない
- 新しい議案を1人で無理なく更新できる

## 非目標

MVPでは以下をやらない。

- 選挙候補者の評価・推薦
- 政党・会派のランキング
- 議員の能力評価
- 選挙予測
- すべての過去議事録の完全収録
- 自動取得の100%無人運転
- AIインタビュー
- 全区政データの統合
